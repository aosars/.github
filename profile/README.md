<h1 align="center">AOSAR</h1>

<p align="center">Automotive Basic Software</p>

[English](https://github.com/aosars/.github/blob/main/profile/README.md) · [简体中文](https://github.com/aosars/.github/blob/main/profile/README.zh-CN.md)

AOSAR is an independent automotive basic software (BSW) project. We are starting with Classic, with a longer-term direction toward Adaptive and service-oriented architectures (SOA).

Our goal is a modular software foundation with clear interfaces, reusable components, and support for integrating existing operating systems and platform software.

AOSAR is in early development. Implementation repositories and technical documentation are being prepared for future publication.
