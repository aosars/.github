<h1 align="center">AOSAR</h1>

[English](https://github.com/aosars/.github/blob/main/profile/README.md) · [简体中文](https://github.com/aosars/.github/blob/main/profile/README.zh-CN.md)

AOSAR 是一个独立的汽车基础软件（BSW）项目，从 Classic 起步，长期面向 Adaptive 与面向服务的架构（SOA）发展。

我们希望构建模块化的软件基础，通过清晰的接口和可复用的组件，支持与现有操作系统及平台软件集成。

AOSAR 目前处于早期开发阶段，正在整理实现仓库和技术文档，为后续公开做准备。

AOSAR 自有的代码与文档采用 [Apache-2.0](../LICENSE) 许可证。第三方组件仍适用各自的许可证。
